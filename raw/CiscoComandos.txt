vlan [vlan_id]
name [vlan_name]
end
>fim<

>>criar vlans em modo access
interface [vlan]
switchport mode access
switchport access vlan [id]
no shutdown

>>criar vlans em modo trunking
interface
switchport mode trunk
no shutdown

access - vlan para dispotivos finais - serve para passar apenas uma vlan
trunking - vlan switch a switch ou switch a router - serve para passar mais de uma vlan

switchport trunk allowed [id]
switchport mode trunk - deixa passar todas as vlans

show vlan brief - mostra as vlans criadas

>>desligar todas as interfaces<<
interface range [fa0/1-24], giga0/1-2
shutdown

>>Limitar accesso de vlans<<
switchport trunk allowed [id] - passa apenas x vlans
switchport mode trunk - deixa passar todas as vlans

>>>>PORT SECURITY<<<< - usar apenas em modo acesso e não esquecer de colocar a interface em modo acesso

>switchport port-security - ativar o port security

>switchport port-security maximum [nº] - número máximo de mac addresses naquela porta

>switchport port-security violation [modo de violação] - definir modo de violação

>switchport port-security mac-address [mac-address] - definir estáticamente

>switchport port-security mac-address sticky mac-address - definir automáticamente, aprende o primeiro mac address que passar

modos de violação:

- protect
- restrict
- shutdown

>show port-security [interface] - pede info

>show port-security address - pede info de que mac addresses foram aprendidos

>>>>DHCP SNOOPING<<<<

trusted - vem do servidor dhcp, normalmente do router
untrusted - vem de fora, vem das máquinas, o lado contrário do servidor dhcp

ip dhcp snooping - ativa o dhcp de forma global

ip dhcp snooping [vlan] - ativa o dhcp numa determinada vlan, se usar o comando de cima, tenho de ativar nas vlans também

no dhcp snooping information option - 

>dentro da interface:
	ip dhcp snooping trust - esta porta passa a ser confiável

show ip dhcp snooping binding - mostra a binding table - tabela que regista ips, macs, lease time...

>dentro de todas as portas untrusted LIGADAS (interface range):
ip dhcp snooping limit rate 1 (limite aceitável é 80 a 100) - limita as mensagens do processo DORA, a porta cai

>>>Roteamento Estático
 	- mais seguro
 	- não consome cpu, largura de banda e memória
 	- usado em redes pequenas
 	- alterações feitas na rede, têm de ser manualmente configuradas no roteamento depois
 	
>>>Roteamento Dinâmico
	- usado em todo o tipo de redes
	- adapta-se às alterações feitas na rede
	- consome cpu, largura de banda e memória
