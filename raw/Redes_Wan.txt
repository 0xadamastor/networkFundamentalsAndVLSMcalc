>>>>>>Protocolo EIGRP
	show ip eigrp topology
		P - passive - tá a funcioar
		A - ativa - não tá a funcionar
	show ip eigrp neighbor
	show ip eigrp route - mostra tabela de routing
	debug eigrp packets - mostra pacotes que são enviados e recebidos
Feasible distance - distancia do router até á rede destino + distancia do router até ao router vizinho 1+1+1
Reported distance - Distancia que o router vizinho tem para atingir uma determinada rede de destino 1+1
Successor - melhor rota para atingir uma rede remota
Feasible susccessor - backup da Successor
