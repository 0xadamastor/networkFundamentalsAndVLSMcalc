		Configurar VTP

SWCENTRAL:

enable
configure terminal
hostname SWCENTRAL
vtp domain istec.local
vtp mode server
vtp password cisco

SWLEFT:

enable
configure terminal
hostname SWLEFT
vtp domain istec.local
vtp mode client
vtp password cisco

SWRIGHT:

enable
configure terminal
hostname SWRIGHT
vtp domain istec.local
vtp mode client
vtp password cisco

Criar VLANs no SWCENTRAL:

vlan 10
name Marketing
vlan 20
name Developers
vlan 30
name Admin

SWLEFT:

interface fa0/1
switchport mode access
switchport access vlan 10

interface fa0/2
switchport mode access
switchport access vlan 20

interface fa0/3
switchport mode access

SWRIGHT:

interface fa0/3
switchport mode access
switchport access vlan 10

interface fa0/2
switchport mode access
switchport access vlan 20

interface fa0/1
switchport mode access
switchport access vlan 30

Trunks (nos switches, entre switches e o router):

interface fa0/24 e gig0/1
switchport mode trunk

Router:

enable
configure terminal
hostname R1

interface g0/0
no ip address
no shutdown

interface g0/0.10
encapsulation dot1q 10
ip address 192.168.10.1 255.255.254.0

interface g0/0.20
encapsulation dot1q 20
ip address 192.168.20.1 255.255.255.0

interface g0/0.30
encapsulation dot1q 30
ip address 192.168.30.1 255.255.255.240

banner motd #ACESSO RESTRITO#
enable secret cisco
line console 0
password cisco
login
logging synchronous
(exit)
service password-encryption

Configurar Telnet no R1

line vty 0 4
password cisco
login

Em todos os switches:

service password-encryption

DHCP no R1 com VLSM

VLAN 10:

ip dhcp excluded-address 192.168.10.1
ip dhcp pool VLAN10
network 192.168.10.0 255.255.254.0
default-router 192.168.10.1
dns-server 8.8.8.8

VLAN 20:

ip dhcp pool VLAN20
network 192.168.20.0 255.255.255.0
default-router 192.168.20.1

VLAN 30:

ip dhcp pool VLAN30

default-router 192.168.30.1

SSH nos switches (VLAN 30)

configure terminal
ip domain-name istec.local
crypto key generate rsa
1024
username admin privilege 15 secret cisco

line vty 0 15
login local
transport input ssh

interface vlan 30
ip address 192.168.30.2 255.255.255.240
no shutdown
(exit)
ip default-gateway 192.168.30.1

Port Security

VLAN 10 (shutdown, mac dinâmico):

interface range fa0/1
switchport mode access
switchport access vlan 10
switchport port-security
switchport port-security maximum 1
switchport port-security violation shutdown
switchport port-security mac-address sticky

VLAN 20 (protect, mac manual):

interface range fa0/2
switchport mode access
switchport access vlan 20
switchport port-security
switchport port-security maximum 1
switchport port-security violation protect
switchport port-security mac-address <MAC>

VLAN 30 (restrict, mac dinâmico):

interface range fa0/3
switchport mode access
switchport access vlan 30
switchport port-security
switchport port-security maximum 1
switchport port-security violation restrict
switchport port-security mac-address sticky

não esquecer de excluir endereços dos switches da pool

DHCP Snooping

ip dhcp snooping
ip dhcp snooping vlan 10,20,30

interface fa0/24
ip dhcp snooping trust

interface range fa0/1-3
ip dhcp snooping limit rate 80-100

no ip dhcp snooping information option (em todos os switches)

switchport trunk allowed vlan 10,20 (caso queiramos que uma vlan não comunique com a outra, util para limitar sshs e telnets)
